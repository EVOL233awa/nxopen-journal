# 逆向重建域（无特征实体 → 可分析/可出图模型）

> 适用：只给一个无特征历史的实体（单特征或导入体），需要重建参数化/可编辑模型并量化精度。
> 前置：`modeling.md`（拉伸/放样/布尔/孔）与 `fea.md`（验证网格）。
> 输入是原件与用户的一句重建要求；测量链见 §10，验收项与失败归因见 §4。
> 按阶段跳转：开工前读 §1.1 与 `modeling.md` §6；测量读 §10 与 §2.1；成形读 §2 与 `modeling.md` §2；某站或某孔不过读 §4.2；收尾读 §7/§9。

## 1. 流程（判据先行）

把工作拆成三个产物，参照物只作数据、不建实体：

- **基线**：精确截面、面积曲线、层界，只作参照。
- **交付件**：参数化实体。
- **核验器**：偏差、视图、剖面、孔表、圆角、编辑测试。

只有 B-rep 边不是直线/圆弧（自由曲面、扫描网格）时，才用分层实体或体素兜底，并在交付说明里标注为近似件。证据优先级：**面表（原始柱/锥/环面）> 精确截面（轮廓）> 渲染图**；每个结构要同时被轮廓和原始曲面确认。测量产物是资产、可复用；从测量到特征的构造要按组件重写，不要因为构造失败而重测。

1. **先定坐标系再测量**：用零件的主承载方向、回转/对称轴和安装面法向建立自然系。所有截面、孔位、出图共用同一变换；存储系与自然系不一致时，只在读/写边界处变换一次。
2. **先转图纸形态，再按正向路线重建**：垂直主轴切截面，间隔按最小结构特征尺寸定并保证每个结构分界都有一刀；另沿其余两轴切过凸台、支臂、凹槽等局部结构。在截面上量取闭合轮廓、孔位与深度，不要靠三角网格“看形猜结构”。截面曲线直接用 §2.1 的 UF 批量接口从 B-rep 取，不要手工在视图上描。动手前先出**结构清单**：面表的圆柱/圆锥组、环面组、槽、腔、凸台、耳座、叉/clevis 开口逐项列出半径/轴/数量与建法（建/简化），清单同时是建模范围与核验的分母；漏掉一组就是漏建一个功能结构。截面出现两条平行壁夹一个开口就是槽/叉，按槽宽与壁厚单独建切除体，不要并进臂的剪影。
3. **按结构建特征，不按层建特征**：先把原件分成组件（回转体、板、臂、耳板、凸台、腔），每个组件用它自己的成形方式——回转体绕零件自身的回转轴旋转、等截面一次拉伸、变截面 5–6 张截面放样、凸台/腔用轮廓或方块布尔。截面是测量数据，不是特征单位：同一组件的所有截面只用来定尺寸和放样，**不逐个拉伸**。顺序按承力路径：主承载基体 → 次级承力结构（筋、凸台、支臂、回转体）→ 局部细节。判据：特征数应与结构数同量级（几十个），改一个臂或一个孔径只动对应特征；每个 z 带一个拉伸的特征树是层号表，不是模型，**禁止作为交付件**（只能作 §3 的基线）。结构尺寸先建命名表达式再绑到特征（配方见 `modeling.md` §1.7 与用例 37）；只有字面值的特征树过不了 G8。
4. **孔系与凹陷作为切除特征后置**：通孔、锥孔、沉孔、减重凹槽、通槽在实体合并后逐个切除，按截面量取的圆心、半径、深度和起止面建工具体，两端各穿出 1–2 mm。
5. **校核顺序**：结构表 → 分区形状（截面 IoU + 三视轮廓）→ 双向偏差 → 体积/包围盒。形状先过关，数值作校核；任一步不达标先回退结构判断，不要靠倒角/拟合修补；按区域逐轮修，每轮只改一个热点并复测，整模重拟合会把已达标区域带偏。体积取净值会掩盖“一处加料、另一处漏建”，另算多料与缺料两份。

### 1.1 结构表（建模前先落这份表）

每个结构一行，字段固定：`结构名 | 证据（面组/半径/轴向区间/测站） | 成形方式 | 特征名 | 自检站`。成形方式取：回转（功能回转体）、等截面拉伸、扇环/阵列、变截面放样（仅头部）、切除体。验收：原件每个功能面组只属于一个结构，每个结构都有成形方式与至少一个自检站，表里没有“其他/杂项”桶。整件剪影闭合后整体旋转、按 z 带逐层放样塔体，都不进入这张表——它们会把环、腔、槽一起填实。

建模按表分阶段，每阶段先过本区形状再进下一阶段：基体（功能回转体 + 板 + 环/筋）→ 臂/耳/叉 → 孔系 → 圆角。阶段间用 undo mark 或独立阶段件隔离，避免局部失败污染整件。清单与站表互查：每张站表写出负责的结构行，写不出就补结构行；同一阶段的主结构先各建一版粗形，再逐个修到门，不把一个结构做到细节后才建下一个。

## 2. 草图—拉伸做法

- 截面曲线直接建在对应高度的基准平面上（`offset` 到 z），沿 +Z 拉伸；批处理下不建 Sketch 对象也能得到与“草图—拉伸”相同的直纹面。
- 闭合样条用 `ufs.Curve.CreateSplineThruPts`（degree 3、`periodicity=0` 开曲线），点序周向一致，首点重复闭合；接缝放在曲率最大处，避免样条在长直段中点起笔。截面折线先做 5 点加权平滑（1-2-3-2-1）再隔点抽稀，抑制采样锯齿；平滑后仍有尖角的位置是真棱线，改用精确直线/圆弧。
- **闭合样条只用开曲线**（`periodicity=0`）；`periodicity=1` 在 NX12 批处理无返回并挂起。
- 矩形/圆角凸台用精确曲线（4 条直线、4 条直线 + 2 个 90° 圆弧），不要让样条穿过 4 个角点（会变成圆角鼓包）。
- **解析边界不要按采样点逐段建线**：圆角、圆孔、圆弧外缘这类半径已知的边界，用精确圆弧 + 直线建截面，半径取面表半径组；把 400 个采样点两两连成 400 条线再拉伸，得到的是 400 张窄平面侧壁，原件同一处是一张圆柱面。判据：交付件的面类型直方图里平面不应占绝大多数，圆弧边界的面类型必须是圆柱（16）/圆锥（17）/B 曲面（43）；折线只作自由段的近似或放样输入，并在交付说明里标注。
- **裸曲线轮廓的轮廓尺寸不可驱动**：`CreateArc`/`CreateLine` 的半径与端点只收 double/Point3d，没有表达式入口；裸曲线拼出的轮廓把长/宽/圆角写成命名表达式后，`DoUpdate` 返回 0、体积与包盒不变、0 告警（静默死参数）。要可编辑就把轮廓放进草图，`AutoDimension` 后把全部驱动尺寸改指表达式（连同定位尺寸 `L/2 − R`，否则改圆角时轮廓整体平移）；或改用方块 + 边倒圆这类特征化等价几何。
- **耳/眼端部按双瓣截形建**：块沿孔轴拉伸，两肩倒 `R_EYE`，端面整圈倒 `R_END` 得环面（构造见 `modeling.md` §2.4）；孔轴带主方向分量时块体沿孔轴拉伸，不沿宽度方向。
- **锥孔的收敛方向按截面半径随轴向的符号定**：面表只给半径与半角，两个方向在面表上同形；沿孔轴取 ≥3 站量孔半径（避开孔口倒角带），拟合 `r(s)` 的符号。起刀面取外端面，轴向起止取面表区间的两端；锥孔用带拔模的拉伸成形，锥度由多个截面的圆心/半径对轴向拟合，不用单个截面直接拉直孔。
- **拔模窗口的起剖面方向**：中面轮廓等于量得轮廓时，起剖面取中面外偏 `h/2·tanθ`，向上按半角收缩；角弧拔模后是圆锥，中面半径 = 起剖面半径 − `h/2·tanθ`，中面截面作验收站。口部圆角在减料后加，顺序见 `modeling.md` §2.4。
- **重复结构先在规范坐标系建一件，再按量得旋转/平移放回整件**：同一窗口/同一耳在多个方位重复时只拟合一次，记录绕主轴的旋转角与平移量，其余方位复制同一特征并施加该变换；不要逐方位重拟合轮廓。
- **扇环窗口的端壁按量得中心线单独建**：端壁可能是非径向直线/圆弧，两端角弧半径可能不同；量每端两个角弧中心，按中心连线建端壁，不用一个对称扇环覆盖全部端部。
- **拉伸后不要删父曲线**：删掉一条轮廓曲线，拉伸会静默换成另一个实体（体积跳到另一量级、0 告警），继续删最终抛 `Update undo happened`；构造曲线只隐藏到独立层，不删除。
- 变截面凸台（根部与端部轮廓不同）用两张正交视图的轮廓各拉伸一次，先 `Intersect` 再并入主体；单轮廓拉伸只能得到等截面，逐层截面拉伸会把凸台切成台阶。
- **`ufs.Modl.CreateExtruded` 的 limits 是“距曲线所在平面的距离”**：曲线画在 z=3、limits 写 [3,16] 得到 z 6…19；要绝对 z 就从 z=0 画曲线，否则 limits 必须减去曲线平面的 z。写错会让窗口/螺栓孔整体平移一个板厚。
- **`Invalid string objects` 是“轮廓无效”，不是参数类型错误**：闭合边穿过过渡弧造成自交时整段拉伸失败，而前 N 段/后 N 段单独拉伸都成功。用分段二分探针（全段/前 N/后 N/去弧/反向）定位到具体段，不要盲改参数。
- **布尔顺序：共面顶面会让切除失效，整圆盘会回填已切孔**：刀具顶面与目标顶面共面时该段不被移除；后建的整圆盘会把先切好的沉孔重新填实。刀具穿过目标面 1–2 mm，并把“补孔”排在任何整圆盘并集之后。
- **“目标区域 = 某形体 − 已建实体”时用 `RetainTool` 反向减**：端部圆顶这类区域用 `BooleanBuilder.RetainTool=True` 让已建实体当刀具但不被消耗，最后再并集；不要重画一遍实体。

### 2.1 从 B-rep 批量取截面曲线（UF，NX12 已验证）

```python
ufs = NXOpen.UF.UFSession.GetUFSession()
# wp = 工作部件；body = 待切实体（NXOpen.Body）

# 截面网格的基准面（位置 + 法向）；平行截面按它的法向等距展开
plane = wp.Planes.CreatePlane(NXOpen.Point3d(0.0, 0.0, 0.0),
                              NXOpen.Vector3d(0.0, 0.0, 1.0),
                              NXOpen.SmartObject.UpdateOption.WithinModeling)

fd = NXOpen.UF.ModlCurveFitData_Struct()
fd.CurveFitMethod = 0          # 0=cubic 1=quintic 2=advanced
fd.MaximumDegree = 3
fd.MaximumSegments = 1

gd = NXOpen.UF.Curve.SectionGeneralData()
gd.Objects = [body.Tag]        # 体/面/曲线 tag 列表（int，不是 NXObject）
gd.NumObjects = 1
gd.Associate = 1               # 1=关联特征；0=非关联曲线组
gd.Grouping = 0
gd.JoinType = 0                # 0=不连接；1/2/3=三次/一般/五次样条连接
gd.Tolerance = 0.01            # 部件单位
gd.CurveFitData = fd

pd = NXOpen.UF.Curve.SectionParallelData()
pd.BasePlane = plane.Tag
pd.StepDistance = 5.0
pd.StartDistance = 2.5
pd.EndDistance = 17.5

feat_tag = ufs.Curve.SectionFromParallelPlanes(gd, pd)
n, curves = ufs.Curve.AskFeatureCurves(feat_tag)   # n=15，curves=tag 列表

# 采样：t 归一化 0..1，返回元组第 0 项是点
for ct in curves:
    for i in range(33):
        p = ufs.ModlGeneral.AskCurveProps(ct, i / 32.0)[0]
```

- 结构体是 `NXOpen.UF.Curve.SectionGeneralData()` / `SectionPlanesData()` / `SectionParallelData()`，字段 **PascalCase**（`Objects`/`NumObjects`/`Associate`/`JoinType`/`Tolerance`/`BasePlane`/`StepDistance`/`StartDistance`/`EndDistance`）；曲线拟合参数用 `NXOpen.UF.ModlCurveFitData_Struct()`，不是 `Curve.CurveFitData`。
- 单平面：`pd = NXOpen.UF.Curve.SectionPlanesData()`、`pd.Planes=[plane.Tag]`、`pd.NumPlanes=1` → `ufs.Curve.SectionFromPlanes(gd, pd)`。`Planes` 是数组，可一次传多个任意方向的基准面（本机只验证单面）。
- **平行面位置语义**：截面在基准面法向上按 `k*StepDistance` 等距生成，再用 `[StartDistance, EndDistance]` 和实体范围裁剪；`StartDistance` **不是**第一张面的偏移。请求 2.5–17.5、步长 5 得到 **5 / 10 / 15** 三张，不是 2.5/7.5/12.5/17.5。
- 返回值：`Associate=1` 返回特征 tag，`FeatureType == "SECTION_CURVES"`；`AskFeatureCurves` 返回 `(n, [curve tags])`。`Associate=0` 按头文件返回曲线组 tag（未验证返回形态）。
- 截面曲线在**绝对坐标系**；直线段是 line（对象类型 3），圆柱孔截面是 **spline（类型 5）不是 circle**——闭合性用首尾采样点距离判，不要按对象类型认圆。
- 采样函数在 `ufs.ModlGeneral.AskCurveProps`（不在 `ufs.Modl`）；返回 `(point, tangent, p_norm, b_norm, torsion, radius_of_curvature)`。孔截面采样点到孔心距离应为常数（r=5.0000、首尾闭合）。
- **端点参数用 0/1，不用 `Eval.AskLimits`**：`AskLimits` 返回曲线内部参数域，把它传给 `AskCurveProps` 会让端点落在错误位置，截面出现开放链。端点取 `AskCurveProps(ct, 0.0/1.0)`；圆弧只从 `Eval.AskArc` 取 center/xaxis/yaxis/R，角度由端点反算，扫掠方向用 0.5 参数点判定。
- **闭环用 `JoinType=0` 原始段自建**：`JoinType=1` 在轮缘端面、腔口、臂端开口处会返回开放“环”。按端点聚类（0.01 mm，失败回退 0.05 mm）串环，再算面积；端点簇度数必须为偶数。
- **重建轮廓直接用 B-rep 精确截面段，不从 STL 重采样**：对每个组件中面取一张 `JoinType=0` 截面，逐段判直线（共线 ≤1e-4）/圆弧（径向偏差 ≤5e-3）/样条；样条段再用直线+圆弧拟合（容差 0.02 mm）；圆弧圆心投影到两端点的垂直平分线，使曲线精确过端点；按端点聚类串环，闭环缝隙 ≤0.001 mm。按这条链建的侧壁是平面/圆柱，与从 STL 重采样再连折线得到的“几百张窄平面”是两种结果。
- **批处理打开刚生成的 prt 会报 `File already exists`**：先把副本放到另一目录再用 `OpenBaseDisplay` 打开，或先打开原件再打开它；同一会话里对已打开的部件再次 `Parts.Open` 也报同一错误。

### 2.2 多截面放样（变截面主体）

按结构选路线：基体、板、环、臂优先用**功能回转 + 等截面拉伸 + 扇环**（一个结构一个特征）；放样只用于沿单一轴连续变化的头部/端部，取 5–6 张结构分界截面（API 见 `modeling.md` §2.2b）。不要对整件只用一种方法，也不要把截面站数直接变成特征数；按 z 带取 18–23 站、单外环放样塔体，是把逐层路线换个写法，槽口会被填实、曲面留下 0.5 mm 级棱面。

**整件剪影闭合后整体旋转会把环、腔、孔全部填实**：回转体只旋转功能回转体（轮毂凸台、轴颈、耳座），板/环/臂/槽各自成形。判据：旋转轮廓的每段半径都对应原件的一个功能回转面；轮廓里出现“板外缘到中心”的长直线段，就是剪影旋转，改回分结构建。

- **先判剪影还是放样，等截面要量化**：同一 z 的多张定 u 剖面 (r,z) 轮廓重合 → 剪影拉伸（等宽段）；只有端部/根部不重合时用放样或局部端盖。每根臂、腹板、耳板都先量底/中/顶三站：三站面积差 ≤2% 且轮廓逐点重合才可单轮廓拉伸，证明写进结构表；不满足就用两张正交轮廓求交或 5–6 张结构站放样，拿单一截面拉整厚会在第三向多料。面积随站位单调变化说明带拔模/收口，按底站与中站两张轮廓分段拉伸或放样，拿中间轮廓拉整厚会两端误差符号相反。
- **低 z 有、高 z 消失的内部开口按窗口切除**：同一板厚内逐层截面出现内环，而上一层内环消失，说明是拔模窗口/斜置切口，不是板厚变化；只按一张外轮廓拉伸会把窗口填实，表现为该 z 带成片多料。窗口按内环的 z 范围与外轮廓单独做切除体。

- **开口/槽不能被“闭合容差”吃掉**：`exact_section` 的 `open_gaps` 给出每条开链首尾距离；大于 `2×tolerance` 的缺口是真实开口（叉口、耳槽、窗口），不是拟合误差。不要放宽容差把首尾硬连成闭环——那会在开口处加一条弦，拉伸后把槽填实。正确路线是先用外轮廓建实体，再按槽/窗口的截面范围做切除体；槽中面截面必须为空。
- **叉/耳的双圆柱是两块耳板，不是一根整圆柱**：同一销孔轴上的两侧 R 圆柱沿厚度方向被槽隔开，只能在槽底以外的根部连接；用等厚矩形把两圆柱整宽桥接会填平槽，在销孔轴法向截面上表现为成片多料。自检取过槽中面的截面，槽区应为空，且两耳板各自闭合。
- 截面取在结构分界上：根部、中段、端部各至少一张；端部取到最后一张有效截面，再往外会落到端面外。
- **统一重采样再放样**：段数/类型不一致时先把每环重采样成同一 N 点闭合折线，再用“开链 + 接缝段”建 Section；点数按弦高定 `N ≥ π·sqrt(r_max/(2·tol))`（`tol` 0.02 mm），不足会在包盒极值与俯视轮廓留削角。参数化按截面相似度选（`modeling.md` §2.2b）；面内基向量取测站平面的两轴（常半径站族的法向是径向，面内轴为切向与 z），先投影验证某轴坐标为常量，取成法向会让射线求交数为 0。
- 放样提交后的体积/片体校验、定位截面、两段同面拼接失败的处理见 `modeling.md` §2.2b；下面只列截面数据与逆向结构本身的处理。
- **截面拓扑可能突变**：同一臂的切向截面可从实心圆角矩形（根部）变为工字型（腹板段）。不要跨拓扑直接放样含凹口的完整环；先放样外轮廓（凸包或外边界），再按各截面的凹入区切除腹板空腔。凸包会把工字型凹口填平，只可作外轮廓，必须再切凹口。
- **外边界取量得外环，凸包只补孔内桥接**：分瓣站逐点取两瓣的外包络（不是整环凸包），放样后再按孔切除；塔体/耳座也用外环，凸包会填平腹板与耳座之间的凹腰（水平站对得上、轴法向截面变窄）。末站与端盖收到量得端面，包盒才不会被放样外推。
- **端部收口不缩放极值截面**：端部最高点取该族最外站的端面，不取中间站；封到端面时沿用最后一站量得轮廓（或 z 窗口裁剪后的同尺寸截面），把末站按 0.35–0.7 缩放成“圆顶”会削掉 +x/+y 极值 0.5 mm，G4 超差。最后一张横截面在端部曲面内部时，用端部截面族的中面轮廓求“半径 → 高度窗口” `[zmin(r), zmax(r)]`，每 4 mm 用窗口裁剪生成过渡截面，过渡截面与主段同一参数化（绕形心等角；按弧长收口会得到体积为 0 的退化实体）。
- **耳座按双瓣截形建，不用臂轴等分站插值**：耳座外形沿臂轴先鼓后收，等分站线性插值会在鼓包处少料、在尖端多料。用块 + 两肩倒圆（§2）建；必须放样时按孔轴截面族（`a+0…a+L`）取 2–4 mm 步长。孔座圆柱只代表孔口包络，不等于耳座外形。
- **臂根建到组件分界以内**：组件区域从分界半径起，但组件登记的最小站常在更外侧；只从该站起建会在整件 z 站缺一块根部。把同族更内圈的截面（含基体上表面）一起放进同一张放样，并在最小门站处加一张内移 2 mm 的定位截面。
- **孔把截面切成两瓣的站要合成外包裹，不能跳过**：水平面正切斜锥孔轴时，孔带沿孔轴拉长并把截面切成两条窄壁。跳过该站会让相邻站直线桥接，凸台外侧那一瓣被削掉。按形心向各方向投射射线、取最外交点合成外包裹，再对包裹取凸包；锥刀随后把孔带切回。两个陷阱：射线包裹在瓣角处会自交，自交截面让放样静默失效（整条臂在该站以上消失、体积却仍在增加，只有切片才看得出）；直接用最近点连线桥接会让桥面沿锥面走，后续锥刀留下零壁厚。
- **凸台端面垂直于斜孔轴时，水平截面族收不出端面**：塔体按水平站放样，端部只能收成水平顶，轴法向站因此在凸台外端短一截。量一张垂直于孔轴的端面截面，沿孔轴向内拉伸成有界棱柱再并，凸台端面才是平面。
- **多闭环站只放样外轮廓**：孔/槽内环单独建切除体或放样后按环切，内外环一起放样会得到错误实体。凸台孔在放样跨度内闭合时（孔外 C 环 → 带孔闭合环），单环放样只能取 C 环、凸台上角被削；这类凸台绕孔轴单独旋转成实体再并，或让 `Section` 同时携带外环与孔环。
- **截面随半径变化的凹腔用放样切除**：腰形减重腔的宽/高沿半径连续变化时，按 4–5 张截面放样成工具体再减；按最宽截面一次拉伸会在窄端多料、宽端缺料，按最窄截面拉伸则切不掉宽端。
- **端盖/圆顶先看面类型再选成形**：面表里端盖是 B 曲面（类型 43）时，用圆柱近似只能对上顶点，侧壁仍差；改取端部截面族的 z 窗口 `[zmin(r), zmax(r)]` 收口，或按端面轮廓单独做回转/放样。端盖是回转面（柱/锥/环）时才直接绕轴旋转。
- 端部若有独立截面族（垂直于孔轴或端面法向的站），用该族截面放样端部，不用矩形块/包围盒近似；C 形开口的末截面无法参与放样时（末站 IoU=0 或放样提前结束），先放到倒数第二站，再用末截面轮廓补端部并单独验证末站。
- 每张截面先做轮廓叠图（面积、周长、闭合）再进放样；放样后按组件门验收——根/中/端三站横剖加一条纵剖的 IoU 都达标，再进下一组件。

## 3. 分层基线（只作测量与核验，不作交付）

**逐层切片拉伸不是交付路线**：它把特征树变成 z 带编号表，改一个臂要改十几层，圆角/孔/凸台都不是特征，且带端封口壁会留下 lump。分层只用于基线、兜底和分区域偏差参照；交付件必须走 §1.3 的结构特征路线（回转/拉伸/放样/布尔/阵列）。B-rep 边是干净直线/圆弧时，5–6 张截面放样即可达到逐层贴合的精度，且特征树保持可编辑。若确有自由曲面只能分层近似，必须在交付说明里标注为近似件，并给出结构特征路线不可行的证据。

按“切除 → 合并 → 圆角”的顺序走：

1. **切除在子体上做完再合并**：邻体边界贴近切除面时，合并会被判成相切求交而拒绝。
2. **合并前裁掉与邻体重叠的冗余块**：残留薄片（<1 mm）会让合并结果非流形；重叠区给 0.5–1 mm。
3. **圆角放到全部分层合并之后**：在孤立子体上倒圆会改变后续合并的终止边，导致 intersection gap。
4. **每刀后断言体积下降、合并后断言体数 = 1**；体数仍为 1 但特征没切掉时，检查目标体/工具体顺序与工具体是否穿过；体数按 Tag 识别（`modeling.md` §2.5）。

约束：
- 合并报 intersection gaps / zero wall thickness 按 `modeling.md` §2.2b 处理；倒圆终止失败按 §9 降级为简化项。
- 人工封口面擦到相邻薄壁：用覆盖式矩形从主体减去封口区域，再把臂/凸台并进来。
- 轴承孔/通孔内留“塞子”：圆柱切除参数把半径当直径，用 `2*R`，切完用体积差验证。
- 凹槽“有形状没凹下去”：切除工具体起点在实体外侧，检查起止高度是否跨过目标面。

## 4. 精度验证与验收门（双向，必须两个方向都算）

- 引擎：二进制 STL 读三角面片 → KD-tree 候选 → 点到三角形精确投影（不要用顶点最近点，误差随网格密度漂移）。
- 采样：两个方向都按面积加权采；不要把全部顶点和面心再并进采样点——密集网格（圆角、曲面）会被过度加权，同一对模型的 RMS 会随采样口径漂移。
- 位置与形状分开：先比包围盒**位置**（冷开直接比，不做自动对齐），再比尺寸；有整体平移时同时报原始与对齐后两组数字，对齐只用于看形状。
- 辅助判据：三视图/轴测的轮廓 IoU、任意剖面的面积与 IoU、多料/缺料空间聚类。轮廓能对上而 RMS 差，说明误差在曲面与圆角，不在外形。
- 剖面填充：切平面与网格平坦面共面时，每条面片边都会被当成穿越，填充出现整片假条纹；切面沿法向偏 0.0137 mm 再切。
- 输出：`mean / RMS / P50 / P95 / max`，两个方向分别统计；再按结构带（用层界和特征边界划分，不用等距分箱）拆分定位系统误差。
- 合格判据取 §4.1 默认档；零件类型只影响采样与对齐做法，不另开放宽档，也不以基线件达标代替。
- 组件级门优先于全局 RMS：每条臂取根/中/端三站，每个孔取孔轴纵剖与横剖，逐项按默认档判定；全局 RMS 会把局部 5 mm 的错误平均成 0.3 mm。
- 偏差热点集中在同一区域 → 结构判断错误；分散且小 → 曲面近似误差，可接受。

### 4.1 验收项

验收基准是原件本身：站表按 §10.1 从原件面表生成，阈值取下表默认值。任务通常只有一句重建要求、不带容差，此时按默认档执行，不等外部检查计划，也不自定更宽的口径；用户显式给出容差时才用用户值。

| 项 | 判据 | 数据源 |
|---|---|---|
| G0 可读性 | 体数、体积、面表可读；两侧都能导出 STL | PRT + STL |
| G1 截面覆盖 | 每个组件与每条边界至少一站、覆盖至少跨两个平面族；**且每站 IoU ≥0.95、面积差 ≤5%** | 测站清单 + 截面 |
| G2 孔系 | 半径、轴向、孔心、锥孔半角 | 面表 + 孔表 |
| G3 体积 | 差 ≤ 0.1% | 质量属性 |
| G4 包围盒 | 位置 ≤ 0.05 mm、尺寸 ≤ 0.05 mm | 两侧 STL 顶点 |
| G5 同站截面 | IoU ≥ 0.99、面积差 ≤ 1% | 截面 |
| G6 双向偏差 | RMS ≤ 0.8 mm、P95 ≤ 1.8 mm | 两侧 STL |
| G7 圆角 | 主组面数覆盖 ≥ 70% | 面表半径组 |
| G8 结构状态 | 单实体、无告警、命名表达式改 ±10% 后体积变化 | PRT 特征与表达式 |
| G9 结构语义 | 特征数与结构数同量级（几十个）、无逐层拉伸堆栈、每个结构能被单独修改 | 特征树 + 编辑测试 |

门结果由独立脚本从交付的 PRT/STL 复算，报告里的自报数字不作证据。特征树可以不同，但**必须是结构特征树**：几何门全过不能替代 G9——逐层切片件可以过大部分几何门，特征树仍是层号表。每个阶段保存 checkpoint，并记录该阶段的体积、体数、门结果。

- **门是阻塞条件，站表与阈值不随自评改**：站表按 §10.1 从原件面表生成，阈值取 §4.1 默认档；阶段门或自检站在阈值以下时不得进入下一阶段，也不得带着已知的低站交付。只报通过站、换一套更宽的站表或阈值、“不含通孔长度”这类自定口径都不作验收，同一组孔按原口径逐项复算。每阶段收尾用该阶段门站复算一遍面积、IoU 与开区，全过再往下建。交付说明逐门列 PASS/FAIL；结构行没有对应特征时按清单补建，不写成剩余偏差。
- **G1 的“覆盖”不等于“合格”，G5 能抓到 G1 漏掉的多料**：只查“每组件 ≥3 站、跨 2 个平面族”会让局部阶梯面很重的件判过；逐带基线的水平站大部分达标时，俯视仍会露出耳板/凸台轮廓外扩。覆盖与逐站 IoU、G1 与 G5 必须一起过。
- **整件开工前先用局部结构证明路线，几何门全过不能替代 G9**：先用“基体 + 一条臂”过组件门与 G9，再建其余结构；逐带基线件可以在体积、包围盒、G5/G6 上达标，但特征树是层号表、改一个臂要动十几层。路线不成立就换结构，不以哪组门先达标为先。
- **G6 的方向不对称是体数探测器**：参考→重建 RMS 小而重建→参考 RMS 大，说明外形贴合但建成件内部多出封口壁——逐带基线合并留下的独立 lump 把带端面暴露成“重建面”。反向偏差过不了时先数体数与 lump，不要继续修外形。
- **G8 存活率要防“还原残差”伪活**：只在开头取一次 `V0`、逐参数算 `dV = V_i − V0` 时，某次还原留下的残差会算进之后所有参数，未接几何的参数也会显示同一个 dV。复核方式：**新会话里单独改该参数 ×1.5**（不是 ×1.1），连续几次空更新作对照；真接了几何的参数在 ×1.5 下仍应有明显 dV，伪活参数为 0。确认伪活后删掉参数、把测量值留作字面量，不要把伪活参数当成交付特征。

### 4.2 失败归因

**先定口径**：同一字段有两种解释 → 先定口径再重建；测量值不可复算 → 修测量脚本，不用建模件补偿；结果与阈值不符 → 先查测量口径、站表与匹配分母，不改阈值迁就结果。差异集中同一区域 → 结构判断或边界选择；分散且小 → 曲面近似误差。核验里 IoU < 0.5 的站是缺结构（端部、耳座、槽、孔），回结构清单补结构，不把这种站平均进 RMS。同一站 z 与 z+0.002 面积差 >10% → 先用两个微米级平面夹住该面读面高（门站可能落在建成面上表面），再决定是否重建，门站本身不用来调形。只在一个平面族失败 → 该方向缺截面证据，补该族测站。

**基体 / 底板 / 窗口**：

- 低 z 站面积偏大且随 z 递减 → 板底有拔模/收口；按量得底站与 z4 外环放样底板，窗口另建切除体。
- 低 z 站 IoU 低、差异沿外边界成带状 → 按该站闭环逐段重建；多料沿底部外环或回转体外圆 → 底板下方有让位结构或外圆有锥形过渡，按该站闭环补切、外圆按量得半径收口。
- 口部圆角与壁面锥/环面半径全对、中截面系统偏小 → 起剖面偏置方向反了；起剖面取中面外偏 `h/2·tanθ`，向上收缩（`modeling.md` §2.2）。
- 窗口/耳端站差 0.5–1 mm、差异集中在端壁 → 端壁按两端量得角弧中心连线建；两端角弧半径可能不同，不用一个对称扇环覆盖端部。

**臂 / 耳 / 叉 / 端部**：

- 臂端站大面积多料、轮廓接近外接方块 → 耳座是双瓣截形，不是沿宽度拉伸的棱柱；棱柱停在耳座切点，耳座按 `R_EYE`、瓣心距、平台宽单独建再并（`modeling.md` §2.4）。
- 包盒极值在臂端且超差 → 臂端是平面斜切/尖头；按两个竖直平面切端头，圆头会在斜向向外凸出。包盒某向短 0.3–0.6 mm 且端部无缺料 → 末站取在端面内侧或收口被缩放；按最后一站量得轮廓封到端面，不缩放极值轮廓。
- 孔把截面切成两瓣、水平站全部对上、竖直截面在端部仍缺料 → 放样面在尖角处向截面之间下垂，加密无效；量一张垂直于臂长的截面，按它沿臂宽拉伸成棱柱再并。
- clevis/耳叉站多料或缺料 → 先确认槽是否切出，再查槽宽与外壁；耳孔在槽壁上切出的弦口属于孔切除边界，不单独补面。俯视 `only_b` 大、差异落在叉口/窗孔 → 单环放样或凸包把开口填实；合并后按量得开口轮廓切通。
- 重复结构只有一个方位对上、其余方位差 → 规范坐标系到整件的旋转/平移没施加；按量得旋转角与平移量复制同一特征。

**孔系 / 凸台 / 锥面**：

- 孔长出现固定差、且差值等于某个面高差 → 刀具上限取了整板顶面；改取该孔自己的端面，入口锪面/倒角单独建（§8）。
- 斜轴凸台的轴法向截面比水平截面窄 1–2 mm → 凸台侧面绕孔轴，水平截面放样只对上水平站；按孔轴单独拉伸或回转凸台再并。锥面轴向起止由凸台端面决定，凸台沿孔轴过厚会把锥面拉长，先修凸台厚度/端面。
- 锥面未匹配、轴向区间或半角差 → 按面表 `point/radius/rad_data` 反算轴向起止，半角用 `rad_data` 的弧度值；孔心与轴取面表组的 `point/dir`，不从截面圆拟合（§8）。
- 锥面半径/半角/轴全对、离中面远的截面偏小 → 锥孔收敛方向反了；按沿轴 ≥3 站半径的符号重建。
- 沉孔底面是锥面 → 不加实心锥填角；按 `modeling.md` §2.3 的 45° 锥刀切底（深度减 `t`、底径 = 孔壁 − 2·t）。
- 扩径后 `Update undo happened`、失败特征是某把切除刀 → 该刀在它的历史位置已无材料可切（完全落入孔/槽空腔）：孔内“先通孔再补一圈料”的浮环脱离孔壁（减径段改三段同轴孔，大-小-大，半径由主直径表达式驱动）；孔口/孔底倒角建在孔后会随孔径扩大被吞掉（倒角切在孔前）；底部锥口建在环槽后会让锥刀落进槽腔（锥口切在环槽前）。通孔下端穿出底面是几何要求（孔底不要停在槽顶），但不解决锥刀悬空。
- 面表圆柱/圆锥的 `point` 是**轴上锚点**（孔轴过 point 沿 dir），`center` 只是 bbox 中心；拿 center/面采样点当轴锚孔轴会偏几毫米到几十毫米。`point==center` 的孔可自证在轴上。面簇 bbox 中心/采样质心不是轴线（弧段不对称会偏），轴向以面表 point 或横截面圆拟合为准。
- 外缘圆柱面 `concave=true` 且截面叠图该处全空 → 是缺口（notch）不是凸台：缺口弧并进所在站的外轮廓，勿建 unite。
- 薄壁贯通切除会静默把件切成多体（Subtract 返回成功、体数变 2）→ 刀具沿壁收进留皮（如 ±(半宽−1)）保单实体，留皮位置按原件壁厚证据；每次布尔后强制校验体数。
- 斜臂下缘随半径上升，水平站是等 z 轮廓、表达不了斜下缘 → 斜结构轮廓以沿特征轴的纵剖面 z(r) 为权威，不用水平站外环。

**圆角 / 端盖 / 参数**：

- 包盒单方向大 0.3–1 mm、极值点落在凸角 → 原件该角有倒圆或倒角；补该角的局部倒圆/倒角，不整件倒圆。圆角/切角参数不能用包盒验证 → 用体积变化 + 该角圆柱面半径（倒圆后还有环面 major/minor）复核。
- 端盖站 IoU 低但顶点 z 正确 → 端盖是 B 曲面；按端部截面族的 z 窗口收口，不继续调圆柱半径。
- 修边/让位刀把无关特征切掉 → 修边盒只覆盖要修的 0.1–0.2 mm，不按“区域”给大盒。相邻两段放样接缝报 "Intersecting target and tool faces" → 两段首末截面来源不同；同一 z 带只用一套截面来源，或让后段从更深处同形截面起。
- 改命名尺寸后部分特征回滚、但几何门全过 → 该尺寸没被所有同轴/相邻面引用；孔内减径段、孔口倒角、孔底让位都写成它的表达式。表达式改了体积不变 → 死参数，接到驱动尺寸或删除，留着判 G8 失败。

## 5. 重建件与原始件的分工

- **FEA**：两件用同一网格尺寸、同一材料、同一载荷，结果差异即几何误差带来的误差带。
- **出图**：原始件用于外形/孔系图（轮廓准确）；重建件出“逆向成果图”，技术要求注明简化项与偏差统计。
- **出图前隐藏全部独立构造曲线/点**：拉伸与切除用的样条、圆弧、点不属于实体，Drafting 视图会把它们当可见几何投影成游离短线/悬空椭圆。重建收尾遍历 `part.Curves`/`part.Points` 逐个 `Blank()`；只隐藏、不删除，避免破坏特征引用。

## 6. 与出图的坐标衔接

- 存储系与自然系相差 45° 时，**不要旋转实体**（批处理下 `UF_MODL_transform_entities` 静默不生效，Drafting 视图拒绝 `View.Rotate`）；改用自定义模型视图，见 `gb-drawing.md` §非轴对齐零件出图。

## 7. 重建件的后续修改

- **尺寸参数化属于交付件**：结构尺寸先建命名表达式，再让特征尺寸绑定表达式（配方见 `modeling.md` §1.7 与用例 37）；只有字面值的特征树在 G8 上 named=0、alive_ratio=0。交付前逐个改 ±10% 并 `DoUpdate`，体积必须变。
- 按序号定位拉伸：遍历 `part.Features`，按 `FeatureType == "EXTRUDE"` 过滤后计数，与界面特征树的拉伸序号一致（重排过的树用 `Timestamp` 复核）；用体积/包围盒变化确认目标。
- NX12 的 `UF.Modl` 无 delete/suppress，`FeatureCollection` 只有 `SuppressFeatures`/`UnsuppressFeatures`；不要写 `ufs.Modl.DeleteFeature`。删除特征走 NX 界面，脚本只做枚举、`GetAllPartFeaturesWithAlerts()` 校核与复测。
- **批量存活检查直接用 `measure.expression_survey(part)`**：它逐条命名表达式 ×1.1、`DoUpdate`、量全实体体积、还原并复核体积，返回 `named/live/dead/broken/skipped/alerts/alive_ratio/pass`；只改内存不保存。交付件必须 `pass=True`（单实体、named≥1、无 dead/broken/alerts、alive_ratio=1.0），不能只挑一个参数验证。
- 交付前跑表达式存活率：逐个命名表达式**先 ×1.1**，`DoUpdate` 后体积必须变；抛 `Update undo happened.` 即 broken，×0.9 通过不算。参数上限留 10% 余量，或把受限尺寸拆成独立参数/字面值；命名不要以 `p`/`P` 开头（大小写都排除：自动表达式是 `p0`、`p1`，`P_D_BORE` 会被一并过滤，named 判 0 而模型本身逐参数有效），参数名用 `D_`、`R_`、`Z_`、`ANG_` 前缀。体积不变的是死参数（特征里用了字面值），接进特征后再交付；多体共用同名表达式时先按体拆名（`modeling.md` §1.7）。
- **公式型表达式不算数值入口**：`A = B + 1.27` 这类右值会被逐项改数值的存活检查跳过；联动可保留系统式，但每个独立结构尺寸都要有数值参数入口（`W_HALF = H_LOBE + R_EYE` 时 `H_LOBE`、`R_EYE` 各自可改，绑定见 `modeling.md` §4.2b）。
- **缩放后保持同一拓扑**：参数 ×1.1 后特征数与面数应不变；面数变化说明圆角滚动/合并，几何已不是同一结构，缩小测试步长或改绑方式。
- **倒角刀完全落入扩大后的孔内时回滚**：孔口倒角若用独立回转体、轮廓半径写死，扩径量超过倒角径向宽度后刀具体整个落进孔内，特征抛 `Update undo`；×1.1 是否触发取决于倒角宽度，不是固定阈值。改用挂在父孔边上的边倒角（随父边更新，扩径后仍存活），或把倒角切在孔特征之前。
- **更新失败定位用 Suppress 或 Accept 模式**：`UpdateManager.SetDefaultUpdateFailureAction(FailureOption.Suppress)` 后 `DoUpdate` 不回滚，返回错误数；`UpdateManager.ErrorList` 用 `Length` + `GetErrorInfo(i)` 读（不可枚举），`Description` 给原因（如 "Tool body completely outside target body."），`ErrorObject/ErrorObjectDescription` 给失败特征，被自动抑制的特征 `f.Suppressed` 为真。`FailureOption` 含 Undo/Interrupt/Suppress/SuppressAll/Accept/AcceptAll/Delete/DeleteDependents/NoOption；Accept 同样能定位失败特征。试完还原 RHS、Unsuppress 全部再 DoUpdate；Undo 模式只抛 `Update undo happened.`，拿不到失败特征。
- **孔深落进后续锥面切削区时表达式必死**（×1.1 后切削区被吞、体积不变）：该深度用字面值，不留死表达式。

## 8. 组件闭合与切除边界

- **每个组件用自己的完整截面集建**：根部、中部、端部三站起步；端部形状（圆头、C 形开口、倒角）属于本体特征，直接进末截面或按端面轮廓切除。
- **布尔只做连接**：并/差发生在接口处；不要用球冠/方块求交修端部，会留下凸块并吃掉开口。
- **切除边界取原件的边界面**：任何切除的起止要对到原件的一个平面/曲面/端面，并在报告里写出该面的类型、位置、tag；不要用“最后一个还能看见这个特征的截面”当边界。凹槽的起止通常是臂端面与一块倾斜起始面，按可见区间做窗口会两头都短。
- **截面与面表双证据**：截面给外形，面表给原始曲面。圆孔在截面里可能只显示为一个开口，必须用面表的圆柱面（半径、轴向、孔心）确认；两腿之间的矩形槽与圆孔同时存在时，按面表的圆柱面建孔，再按截面建槽。
- **堆叠层各用各的截面**：相邻层的窗口/缺口形状、角度和半径可以完全不同；沿用相邻层会整层多料。
- **凸台顶面与板顶不在同一高度**：螺栓凸台顶比板顶低一个台阶时，把沉孔切到板顶会把孔壁加长这个台阶高度。刀具上限取该孔自己的端面，不要用整块板的顶面。
- **孔包入口与入口锥分开建**：`HolePackageBuilder` 的刀具在孔位之前固定延伸约 2 mm，孔壁起点更靠近入口面时会切掉入口外材料（孔壁变短、入口塌边）；按面表轴向区间建独立圆柱切除体，起止各穿出 1–2 mm。孔包一次成型还会把入口锥与孔壁绑在同一特征，改孔深会同时改锥面位置；按孔表把孔壁与入口锥拆成两个切除体，锥面按面表半径/半角建。
- **锪面深度校验**：`HolePackageBuilder.Validate()` 要求孔深大于锪面深度，锪面深度由 `(锪径 − 孔径)/2/tan(半角)` 决定；即使通孔已经切好，也把孔深写成该值加 1 mm 再提交，锥面只切入口那一圈。
- **孔壁长度比原件长 0.5–1 mm 的整倍数** → 建成件的孔壁顶到了入口倒角或锪面占掉的那一段。孔壁长度是两端面之间的净长，锥段不计入；先建入口倒角再复测孔长，不要靠缩短孔深去凑，那会把孔底一起缩短。
- **G2 半径/孔心/轴全对、只有长度差一个或几个过渡段** → 自建件用一根直孔贯穿了原件由同轴多半径段组成的孔（沉孔/锪面/退刀槽/锥段）。按 `group_coaxial` 的半径分桶逐段建切除体，长度取各段自己的面表轴向区间；不要用总深拉一根孔再解释为“过渡简化”，那会在每段端面留下整圈多料/缺料。
- **切除工具体穿过目标面 1–2 mm**；停在目标面上会留下封口薄片。
- **组件门站与 region**：臂/凸耳类组件在扇区内的 z 截面切到的主要是基座板料，检查点从上一组件检查点起建（`BASE ∪ 本组件`）；region 只裁“不属于该组件”的区域（臂扇区、clevis 盒），用 `radius_max` 按固定半径裁外边界会把背侧筋板一起裁掉，组件门全过而整件 z 站缺料。区域外材料不参与截面/包围盒门，体积自洽门只比该 PRT 与自身 STL，单实体门仍要过。
- **门站恰好落在水平面上时先查面高**：上表面比参考低一个微小台阶时，门站在 z+0.002 切片会直接越过旧上表面，把高度误差放大成面积缺口。判据：同一站在 z 与 z+0.002 两个平面的面积差 >10%、且缺料沿一条水平边界分布时，先用两个微米级平面夹住该面读面高，再决定是否重建组件。
- **薄层补片布尔**：补片与既有实体共面（上表面、窗口侧壁）时 `CreateUniteFeature` 报 `Intersecting target and tool faces may have problems that cause intersection gaps`。把补片多边形 `buffer(-0.1)`、顶面停在参考面下 5 µm，再并；补片只增几百 mm³ 也能把门站截面补回。
- **占位/切除盒的底面落到基体底面**：盒体从组件的实体起点起建时，参考在该起点以下的足迹里可能仍有板料；把盒体下延到基体底面。组件的“实体起点”与“它占住的基体空间”不是一回事，盒体按后者建。
- **孔按孔表建独立切除体**：孔心、轴向、半径、半角取孔表，不从截面环拟合（孔心容差 0.05 mm 比截面拟合更严）；外形拉伸成实心，再按 `center/axis` 建圆柱/圆锥切除体，孔口倒角另做。把带孔截面切成几块分别拉伸会让孔变成竖直槽，孔表复算整组缺失。

## 9. 圆角阶段

- **圆角是交付前的固定阶段**：主组覆盖 ≥70% 是报告项，但圆角同时影响端站/孔站截面 IoU；未建圆角必须逐组写入简化清单，不能默认省略。
- 先出**圆角地图**：从面表按（半径组、轴向、bbox 区域）分组，映射到边链，记录每组预期面数；原件环面与圆柱面的半径组就是地图的输入。
- 按组选边：同半径、同 bbox 区域、同轴向三条同时满足才归一组；边集用 exact（按坐标/拓扑筛出的边），不要用 ring（会把曲面缝边带进来，上游尺寸一变就失效）。
- 顺序：子体上先倒圆再合并，合并后只补跨体边；大半径先、小半径后。
- 验收：重建件与原件按半径组统计面数，主组（面数最多的两组）覆盖 ≥70%；不达标就补组，不留在交付说明里。
- 无法终止的边（凹角、薄壁 ≤1.5 mm）降级为简化项，记录位置、半径、原因和对偏差的影响。
- **交界交线先看段长，再决定能不能倒**：候选链的 `总长 / 段数` 低于约 1 mm 时，放样+布尔留下的交界是几百段微边，`EdgeBlend` 会分别报 `Unable to terminate the blend faces`、`Unable to apply blend`、`blend rolls across a sharp edge`。做法：把根部外扩（flare）放进最后 2–3 张臂截面（圆角或切向收出），让过渡成为放样曲面的一部分；或先合并切向面、把交界恢复成长链，再按组倒圆。

## 10. 测量链（原件 → 可建模数据）

输入是原件与用户的一句重建要求；测站由原件面表按 §10.1 生成，验收阈值取 §4.1 默认档，并写入交付说明。组件按承力路径与可独立放样的几何单元划分。任务没给容差是常态，不据此自设更宽口径。

1. **一次探针取全量事实**：体数、逐体体积、面表（`tag/type/point/dir/box/radius/rad_data`）、特征与告警、表达式、草图状态；全部落盘后再分析。包围盒入口在 `ufs.ModlGeneral`：

```python
approx = ufs.ModlGeneral.AskBoundingBox(body.Tag)
origin, axes, lengths = ufs.ModlGeneral.AskBoundingBoxExact(body.Tag, 0)
```

`AskBoundingBoxExact` 的 `origin` 是盒角点、`lengths` 是全长；`ufs.Modl.AskBoundingBox` 与 `Body.GetBoundingBox` 在 NX 12 不存在。B 曲面用 `AskBoundingBox` 偏保守，`AskBoundingBoxExact` 的有向盒可能含未裁剪曲面外延，逐面盒并集只对解析面贴合；门比较改用两侧导出的 STL 顶点。

- **B 曲面（类型 43）的 `AskFaceData` 参考点返回 (0,0,0)**：按 `point` 的半径/坐标筛面会漏掉全部 B 曲面；区域筛选用 `box` 与邻接边。

2. **测站按结构分界布置**：主轴方向取平面坐标断点、柱/锥端面、圆角切点，每个分界至少一站；每个孔取一张过轴平面和一张垂直轴平面；臂、凸台、槽沿其轴线取根/中/端。先写测站清单再测量，缺证据回清单补，测量后不临时加站。

3. **截面批量取**：用 §2.1 的 UF 接口。闭环用 `JoinType=0` 原始段按端点聚类自建（0.01 mm，失败回退 0.05 mm）；每个端点簇度数必须为偶数，每环面积 >0.001 mm²、段数 ≥2，所有点距测站平面 ≤1e-3 mm，圆弧端点满足 `|dist(p, center) - R| < 1e-5 mm`。有旧采样时做面积交叉，差 ≤1%。

4. **顺序不稳定**：`AskFeatureCurves` 返回的曲线集合相同、顺序可变；`Body.GetFaces()` 的 tag 集合相同、顺序可变。曲线写盘前按 `(kind, round(p0, 9), round(p1, 9))` 排序，端点用 0/1 参数重建；面表按几何键排序；聚类用成对谓词的并查集，不用与首元素比较的贪心首匹配；输出按 `(kind, radius/half_angle, center)` 排序，索引型引用才不会漂移。序列化前把 `-0.0` 统一成 `0.0`，体积按固定小数位落盘。判据：同一原件两次独立测量逐文件 sha256 相同。

5. **特征分组**：圆柱/圆锥按 `(unit(dir), radius)` 或 `(unit(dir), rad_data)` 分组；组内并查集按参考点垂直投影距离 ≤ `2R+2` mm 合并。轴向间隙不作分组条件——内孔可被环槽打断，按轴向区间切分会把一个功能孔拆成两段；分组后用截面环复核孔位。孔取功能半径组并与截面圆孔环互证；圆角取环面小半径加圆柱过渡半径，主组按面数覆盖 ≥70%。

   - 小半径轮廓圆弧以面表半径为准：截面里的小角圆弧常被采样成样条，拟合半径可偏 1 mm 以上；建模时把 <10 mm 的轮廓圆弧吸附到自建圆角表里最近的半径组。
   - 孔表按几何键排序；组件配置用（半径 + 孔心）匹配孔，不写死数组下标。

6. **边界目录**：每条边界写 `id`、所属组件、`decision`（`cut`/`integrated`/`deprecated`）、`carrier`、`source`、`expected`。`carrier` 必须是真实存在的测站或环；`expected` 要能由测量层复算；`deprecated` 写明为什么不建，不用“看不见”当理由。

7. **结构判读用统计量，不用视图目测**：
   - 臂方位：多个 z 层的环形心角取中位数（目测会把整组截面切空）。
   - 孔轴：切向截面出圆 = 轴沿径向；定 u 剖面出圆 = 轴沿切向；两种都出椭圆时按长短轴比反解倾角。
   - 层界：某环在哪个 z 消失；径向边界：某角度射线在哪个 r 断开。
   - 把量得的 z 当刀具上限前，先沿轴向射线扫一遍原件，确认该 z 之上确实是空的；截面环只能说明“那里有面”，不能说明“面之上有没有料”。

8. **测量可复用，构造要重写**：精确截面、面表、圆角分组是昂贵资产；修版时复用测量、只重写有问题的组件，不要重测。测量数据与建模输入分开落盘，重建件按组件 checkpoint 保存。

### 10.1 测量与比对（`nxlib.measure`）

用 `nxlib.measure` 量原件、量自建件、再比对；两条链都是只读打开、不保存部件：

```python
from nxlib.measure import (open_part, measure_part, compare_parts,
                           export_mesh, read_stl, mesh_bbox,
                           section_area, section_iou)

orig = measure_part(ORIG)              # 体积/体数/特征数/面表/圆柱组/圆锥组
built = measure_part(BUILT)
cmp = compare_parts(ORIG, BUILT)       # 圆柱/圆锥组按轴+半径匹配，给长度/中心/轴差
mesh_o = read_stl(export_mesh(open_part(ORIG), STL_ORIG))
mesh_b = read_stl(export_mesh(open_part(BUILT), STL_BUILT))
bbox_o, bbox_b = mesh_bbox(mesh_o), mesh_bbox(mesh_b)
area = section_area(mesh_b, (0.0, 0.0, z), (0.0, 0.0, 1.0))
iou = section_iou(mesh_o, mesh_b, (0.0, 0.0, z), (0.0, 0.0, 1.0))
```

- `face_table` 给 `type/point/dir/box/radius/rad_data`；`group_coaxial(faces, "cylinder")` 按轴+半径聚组，`hole_params` 给直径/轴/中心/轴向长度/端面，`cone_params` 给 UF 参考半径与半角（度）。
- **重建截面取 B-rep，不切 STL**：`exact_section(part, origin, normal)` 用 UF `SectionFromPlanes` 返回原始段采样点与按端点串好的闭环（`loops[].pts/closed/abs_area/gap`，未闭环缺口汇总在 `open_gaps`）；轮廓的直线/圆弧从这些点拟合，STL 只用于最终偏差与轮廓比对。STL 切面在孔口、斜面和薄壁处会把解析边界重采样成折线，特征树随之变成窄平面墙。
- `export_mesh` 走 DexManager STL（弦高 0.01 mm），`section_outline` 按三角面外法向定向闭环：外环正面积、孔环负面积，净面积取代数和；`section_iou` 用扫描线算两截面交并比；`mesh_bbox` 给 STL 轴对齐包盒，用于 G4 的位置与尺寸。
- 闭环顺序：量原件 → 建 → 量自建件 → 比 → 只修差异所在的结构 → 再量。G0/G2/G3/G4/G5 都能在这条链上核验（G5 用 `view_iou` 的 top/front/side 轮廓）；G8 直接调 `expression_survey(part)` 一次查完全部命名表达式（判据见 §7）。分母取原件功能结构清单，阈值取 §4.1 默认档；核验数字与独立复算不一致时先查分母和站表。
- **自检未过不得当作完成**：`verify_parts` 报 G1/G2/G3/G4/G5/G6 任一项失败时继续迭代，不能把“已知残差”写进报告就交付。先按失败站的 `only_a`/`only_b` 排序：`only_b` 大的站是过建/未切窗口/槽被填，`only_a` 大的站是漏建结构；把最大的 3 个结构修完再重跑。G6 的 `max>3 mm` 簇优先当结构误差（拔模、收口、槽、窗口），不要先加圆角掩盖；结构门接近后仍差 0.8–3 mm 的簇，再按圆角半径族补边倒圆并重跑 G5/G6。
- **G1 的 only 面积是修结构的主指标**：`station_report` 每站给 `only_a`（原件有、自建缺）与 `only_b`（自建多出），面积差百分比只说明总量。`only_b` 在多个 z 带同时出现且数值相近 → 查该结构的等截面拉伸/未切窗口；`only_a` 在槽/孔轴法向站集中 → 查槽是否被桥接填实或孔端过渡是否漏建。局部单点差异先做角度-半径剖面（极角分桶 rmax 对比）定位方位再动手。
- **测站避开轮廓台阶高度**：`exact_section` 切在台阶/顶点值（±0.2 mm）会产生环分裂与开环伪影，该站读数不可当结构差；层叠结构各层外缘不同，按层分别取截面。
- **比对的分母是原件，且先筛功能清单**：`unmatched_a` 是“原件有、自建件没有”的结构，逐项建或写入简化清单；原件侧先用截面圆孔环（§10.5）或孔表筛出功能孔/锥组，作为 `ref_a` 传给 `compare_parts`，圆角/凸台/外圆的圆柱组不计入分母。只报 `unmatched_b` 会把漏建结构当成通过；`unmatched_b` 逐项确认是孔还是圆角/凸台，多出的圆角组不算漏建。
- **通用几何门用一次汇总**：`verify_parts(orig, built)` 按原件面表生成测站（平行平面族每偏距一站；圆柱/圆锥沿自身轴取根/中/端），逐站比 IoU/面积，再比孔锥、体积、包盒、top/front/side/iso 轮廓与双向偏差（G0–G6）。偏差用 `mesh_deviation`：双向面积加权与精确点—面距离，`sample_surface` 固定 seed 可复现；长度按 `measure_part` 的 `length_scale` 换到毫米。`station_plan` 受 `max_stations` 约束，`dropped>0`/`complete=False` 表示有边界未测，需按结构表另补站，不能把自动站表当全覆盖。G7 为报告项，G8/G9 仍按 §7 与 `modeling.md` §6 单独检查。
- **匹配成功不等于合格，结论只取整链布尔值**：`pass` 按 G2 阈值逐项判（圆柱半径 0.025、孔心 0.05、轴 0.1°、长度 0.1；圆锥加半角 0.1°），已匹配但超差的项按 `delta_radius/delta_center/delta_length/delta_half_angle_deg` 修到阈值内；`verdict = cmp["pass"]`，它要求原件功能组全部匹配且逐项过阈值；`unmatched_b`（多出的圆角/凸台组）只作复核，`strict_pass` 才要求两组全匹配。`pairs` 数量或“匹配上的组数”不作通过证据；原件有圆锥组却用圆柱代替时 G2 直接失败。
- **面表先出结构假设，再动手**：同轴圆柱/圆锥成组 → 回转；大平面为主、圆柱少 → 棱柱基体 + 孔切除；环面成组 → 圆角地图；B 曲面 → 端盖/过渡面，按截面族收口；同轴同半径被环槽打断 → 一个功能孔，按轴向区间整体建一个切除体。
- **截面核验取结构分界站**：站表从面表生成（水平站取全部水平平面族的 z；功能孔取轴向端点与中点并沿孔轴法向各取一站；每个结构沿自身轴线取根/中/端，开口与槽另取槽底与两端），取原件结构分界的全集，不只取建模用到的站；只取 z 站会给出高通过率而与整门相反，失败集中在斜向、耳孔与凸耳站。每个组件根/中/端各一站，孔取过轴与垂直轴各一站；面积差与 IoU 同时看，面积差小但 IoU 低说明形状错位，IoU 高但面积差大说明孔/槽环没减掉。
- **交付前比每个组件的轴向跨度**：对每条臂、每个凸台，沿它自己的轴线取原件与自建件 STL 顶点的投影极值，逐组件比 `max_proj`/`min_proj`，差 >1 mm 就是该组件端部缺失或外推；再把末段按 2–5 mm 切片比面积，看鼓包是否被插值削平。只比 z 平面站查不出这类缺口：端部沿臂轴缺料时，水平截面常常只差几百 mm²，却在孔轴法向站和包盒上同时超差。
- **交付前数拓扑**：`len(part.Curves)`、面类型直方图、面数与原件比。构造线建完特征后删掉或隐藏，不留在交付件里；平面占面数八成以上、而原件有成组的环面/圆柱面，就是解析边界被折线化了；视图里密集的纵向面边界同因，按解析边界重建；面数比原件多一倍以上先查这一条，再查截面精度。
- **圆锥组按 (轴, 半角) 分桶，圆截面放样会把一个锥面拆成多组**：把直线剖面回转面拆成多个圆截面放样后，面表里出现半径不同、半角在 5°–90° 之间连续跳变的同轴锥组，`compare_parts` 报“原件一组缺、自建件多组”。判据：圆锥组数超过原件一倍，或同轴锥组的半角分散；先把该段改成单段直线剖面回转或一个圆锥体，再比孔/锥参数。
- **同类数值修正只做一次**：孔长、锥面分组、截面站各改一处后复测，仍不过就记录该数值项的残差，转去补其他结构；结构缺失不按数值项处理，回结构清单补特征，不写入简化清单。`unmatched_b` 里的非功能多出面（锥带、凸台、圆角）不计入缺陷。几何与结构门做齐后再补圆角，但 G6 仍超差时圆角不能省略：按原件环面/过渡面的半径族取边倒圆，补完重跑 G5/G6；G7 只是覆盖率报告项，不能替代 G6。
- **放样告警同样算 G8 失败**：`THRU_CURVE` 在截面单瓣/两瓣交替、相邻截面外凸顺序反转时报更新告警；抽稀到同拓扑截面，或改成单瓣凸包外廓 + 切除，再复算特征告警。
