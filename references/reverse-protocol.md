# 逆向复现协议（测量 → 建模 → 验收）

> 适用：只给原件与检查计划，要求重建结果可复核、两个独立会话能走到同一组判据。
> 域配方（截面放样、切除、圆角、偏差）见 `reverse-engineering.md`；本文件只定义数据契约、判据与重放方法。

## 1. 数据契约

重建会话只读三类输入，尺寸与拓扑决策必须能追到其中一项：

| 输入 | 内容 | 约束 |
|---|---|---|
| 原件 | 只读 `.prt` | 不保存、不另存、不修改 |
| 检查计划 | 测站列表（位置/法向/名称） | 每站覆盖一个结构分界 |
| 任务配置 | 组件划分、边界 id、门阈值、容差 | 不含建模做法 |

产物分三层，互不替代：

- **测量层**：`sections.json`、`holes.json`、`fillets.json`、`boundaries.json`、`part.json`。
- **建模层**：`BUILD_PLAN.md`、组件 checkpoint、合并件、`parameters.json`。
- **验收层**：`qa/` 下由独立脚本从 PRT/STL 复算的门结果。

任何尺寸只能引用测量层字段或协议规则；引用包外文件、口头结论或上一轮产物都不合法。计划里每条边界写 `decision / carrier / source`，`integrated` 的 `carrier` 必须是测量层真实存在的测站或环。

## 2. 测量链

### 2.1 探针

一次批处理取全量事实，落盘后再分析：

- 体数、逐体体积、三种包围盒估计。
- 面表：`tag / type / point / dir / box / radius / rad_data`。
- 特征列表、告警、表达式、草图状态。

包围盒入口在 `ufs.ModlGeneral`：

```python
approx = ufs.ModlGeneral.AskBoundingBox(body.Tag)
origin, axes, lengths = ufs.ModlGeneral.AskBoundingBoxExact(body.Tag, 0)
```

`AskBoundingBoxExact` 返回 `(origin, axes, lengths)`：`origin` 是盒角点，`lengths` 是全长；求角点用 0/1 偏移，按 ±1 取半长会把盒放大约一倍。`ufs.Modl.AskBoundingBox` 与 `Body.GetBoundingBox` 在 NX 12 不存在。`AskBoundingBox` 对 B 曲面偏保守；`AskBoundingBoxExact` 返回有向盒，可能包含未裁剪曲面的外延；`ufs.Modeling.AskFaceData` 的逐面盒并集只对解析面贴合。**门比较不要用这三种估计，改用两侧导出的 STL 顶点**。

### 2.2 截面

对每站建基准面并切分：

```python
gd.JoinType = 0          # 逐段，不连接
gd.Tolerance = 0.01
feat_tag = ufs.Curve.SectionFromPlanes(gd, pd)
n, curves = ufs.Curve.AskFeatureCurves(feat_tag)
```

- 端点固定用 `ufs.ModlGeneral.AskCurveProps(ct, 0.0)` / `(ct, 1.0)`；`Eval.AskLimits` 返回内部参数域，不能当 0..1 参数用。
- 直线取两端点；圆弧从 `Eval.AskArc` 取 `center/xaxis/yaxis/R`，角度由端点反算，扫掠方向用 0.5 参数点判定；其余曲线在 0..1 采 81 点。
- `JoinType=1` 在轮缘端面、腔口、臂端开口处会返回开放“环”；闭环只用 `JoinType=0` 原始段自建。

### 2.3 顺序不稳定

NX 不保证跨会话的枚举顺序：

- `AskFeatureCurves` 返回的曲线集合相同，顺序可变；直接写盘会让同几何产生不同字节。
- `Body.GetFaces()` 的 tag 集合相同，顺序可变；按首次出现位置做贪心聚类会得到不同分组。

处理规则：

- 曲线写盘前按 `(kind, round(p0, 9), round(p1, 9))` 排序；端点用 0/1 参数重建。
- 面表分析前按几何键排序；聚类用**成对谓词的并查集**，不用“与首个元素比较”的贪心首匹配。并查集的分区只由谓词决定，与输入顺序无关。
- 输出（孔、锥、圆角组、平面组）按 `(kind, radius/half_angle, center)` 排序，索引型引用才不会随会话漂移。

### 2.4 串环与校验

端点按 0.01 mm 聚类，失败回退 0.05 mm；每个端点簇度数必须为偶数；每环面积 > 0.001 mm²、段数 ≥ 2；所有点距测站平面 ≤ 1e-3 mm；圆弧端点满足 `|dist(p, center) - R| < 1e-5 mm`。有旧采样时做面积交叉，差 ≤ 1%。

### 2.5 特征分组

- 圆柱/圆锥按 `(unit(dir), radius)` 或 `(unit(dir), rad_data)` 分组。
- 同组内用并查集合并：两面的参考点垂直投影距离 ≤ `2R+2` mm 即同组。轴向间隙不作为分组条件——内孔可能被环槽打断，按轴向区间切分会把一个功能孔拆成两段；分组后用截面环复核孔位。
- 孔取功能半径组（与截面上的圆孔环互相确认）；圆角取环面小半径 + 圆柱过渡半径。圆角组按半径统计面数，主组覆盖 ≥ 70%。
- 孔表输出前按几何键排序；组件配置用几何键（半径 + 孔心）匹配孔，不要写死数组下标。

### 2.6 边界目录

每条边界至少包含：

- `id`、所属组件、`decision`（`cut` / `integrated` / `deprecated`）。
- `carrier`：切除工具体的起止面，或承载该轮廓的测站/环引用。
- `source`：测量层字段路径，例如 `holes.json#[radius=7.506]`、`boundaries.json#ARM45_GROOVE.expected.z_floor`。
- `expected`：可由测量层复算的数值（面积、深度、半径、角度）。

`deprecated` 必须写明为什么不建；不得用“看不见”当理由。`integrated` 不得指向不存在的测站。

## 3. 建模

- 按组件划分与 `build_order` 逐个建；每个组件用自己的完整测站集（根/中/端），先写 `BUILD_PLAN.md` 再开建。
- 组件门区域可能与相邻组件重叠：根部按区域内的参考截面建到分界外 1–2 mm，不要只在分界面贴 0.1 mm 薄片；低 z 站的缺料会直接反映在截面面积差上。
- 主体优先多截面放样；局部结构用切除。切除工具体穿过目标面 1–2 mm，不在目标面上停刀。
- 每个组件单独过组件门（覆盖、孔、体积、包围盒、截面 IoU），再合并；合并后过整件门。
- 特征树可以不同；判据是几何门与边界决策，不是特征数。
- 每阶段保存 checkpoint，并在报告里记录该阶段的体积、体数、门结果。

## 4. 验收门

| 门 | 判据 | 数据源 |
|---|---|---|
| G0 | 体数、体积、面表可读；原件与重建件都能导出 STL | PRT + STL |
| G1 | 测站覆盖每个组件与每个边界；覆盖至少跨两个平面族 | 检查计划 + sections |
| G2 | 孔半径、轴向、孔心、锥孔半角 | 面表 + 孔表 |
| G3 | 体积差 ≤ 0.1% | 质量属性 |
| G4 | 包围盒位置/尺寸差 ≤ 0.05 mm | 两侧 STL 顶点 |
| G5 | 同站截面 IoU ≥ 0.99、面积差 ≤ 1% | sections + 重建件截面 |
| G6 | 双向偏差 RMS/P95 在阈值内 | 两侧 STL |
| G7 | 圆角主组覆盖 ≥ 70% | 面表半径组 |
| G8 | 装配/表达式状态；单实体任务用单实体门 | PRT 特征与表达式 |

门结果必须由独立脚本从交付的 PRT/STL 复算；报告里的自报数字不作为证据。任一停止条件（工具失败、包缺陷、门无法计算）写 `BLOCKED.md` / `TOOL_FAIL.md` 并停止，不用改门阈值绕过。

## 5. 双盲重放

- 两个全新会话、同一组输入、各自独立输出目录；互不读对方产物，主线程不口述尺寸或做法。
- 每轮先跑工具自检（同件视图 IoU、同件偏差、同站截面），自检不过先修工具，不进入建模。
- 验收口径：
  - 两轮各自过门（G0–G8，单实体任务用 G8c）。
  - 两轮数值收敛：体积 ≤ 0.1%、包围盒 ≤ 0.05 mm、同站截面 IoU 差 ≤ 0.01、孔心 ≤ 0.02 mm、轴向 ≤ 0.05°、锥孔半角 ≤ 0.05°。
  - 边界决策不要求逐行相同；每条边界合法、承载存在、差异有记录即可。
- 同一输入下两轮门结论相反，判为复现缺陷，归因到包/协议/工具；不归因于建模水平。
- 任一轮 `BLOCKED`，修包/协议后派新会话，不续跑旧会话。

## 6. 失败归因

先查数据契约，再查协议歧义，最后才查建模：

- 同一字段有两种解释 → 补协议定义，重跑。
- 测量层数值不可复算 → 修测量脚本或包，不用建模件补偿。
- 门阈值与零件类型不匹配 → 改门配置并写明依据，不悄悄放宽。
- 两轮差异集中在同一区域 → 结构判断或边界选择问题；差异分散且小 → 曲面近似误差。
- 截面门在低 z 站缺料 → 组件根部没有建到相邻组件分界外；在端站缺料/多料 → 末截面没有纳入放样或端部轮廓取错；在孔站面积差 → 孔环没有减掉或锥角取错；只在一个平面族失败 → 该方向没有截面证据，补该族测站。
